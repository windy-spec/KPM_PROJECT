WAREHOUSE MATERIAL REQUEST FLOW UPDATE
===================================

Ngày cập nhật: 2026-07-02

Mục tiêu:
- Tách luồng quản lý yêu cầu nhập vật tư thành 2 vai trò riêng biệt:
  1. Admin: duyệt mua
  2. Kho: nhập kho thực tế
- Đồng bộ giao diện kho với phong cách admin để dễ nhìn và thống nhất hơn

1. Các thay đổi đã thực hiện
--------------------------------

1.1 Tách component cho Admin
- Tạo component mới: frontend/src/components/admin/AdminMaterialRequestApproval.jsx
- Chức năng:
  - Hiển thị danh sách yêu cầu nhập vật tư
  - Admin chỉ thấy nút "Xác nhận Mua"
  - Khi bấm, hiện confirm modal để xác nhận duyệt mua
  - Sau khi duyệt, trạng thái chuyển sang "Đang giao hàng"

1.2 Tách component cho Kho
- Tạo component mới: frontend/src/components/warehouse/WarehouseMaterialRequestReceive.jsx
- Chức năng:
  - Hiển thị danh sách yêu cầu nhập vật tư đã được admin duyệt
  - Kho chỉ thấy nút "Nhập Kho"
  - Khi bấm, hiện modal nhập số lượng thực tế
  - Sau khi xác nhận, gọi API nhập kho và cập nhật trạng thái

1.3 Thay đổi routing/rendering
- Admin dashboard dùng component AdminMaterialRequestApproval
- Warehouse dashboard dùng component WarehouseMaterialRequestReceive

1.4 Đồng bộ giao diện kho
- Chỉnh lại giao diện trang lịch sử phiếu xuất kho:
  - header theo phong cách card giống admin
  - bảng và màu sắc dùng theme thống nhất hơn
  - panel chi tiết mở rộng có bố cục rõ ràng hơn
  - search box và trạng thái loading được làm đồng bộ hơn

2. Các file đã chỉnh sửa
--------------------------------
- frontend/src/components/admin/AdminMaterialRequestApproval.jsx
- frontend/src/components/warehouse/WarehouseMaterialRequestReceive.jsx
- frontend/src/pages/admin/Dashboard.jsx
- frontend/src/pages/warehouse/WarehouseDashboard.jsx
- frontend/src/pages/warehouse/WarehouseExportHistory.jsx
- frontend/src/components/common/ConfirmModal.jsx

3. Luồng nghiệp vụ hiện tại
--------------------------------
- Admin:
  - xem yêu cầu nhập vật tư
  - bấm xác nhận mua
  - chuyển yêu cầu sang trạng thái chờ kho nhập hàng

- Kho:
  - xem các yêu cầu đã được admin duyệt
  - bấm nhập kho
  - nhập số lượng thực tế
  - xác nhận nhập kho

4. Ghi chú quan trọng
--------------------------------
- Logic hiện tại đã tách rõ theo vai trò, không còn dùng chung một component cho cả 2 vai trò.
- Giao diện kho đã được chỉnh gần hơn với phong cách admin để dễ nhìn và nhất quán hơn.
