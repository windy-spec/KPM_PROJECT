Code Guide - Advanced

1) Quy tắc chung
- Tuân thủ cấu trúc component: presentational (UI) vs container (logic).
- Không đặt side-effect trong render; dùng hooks (`useEffect`, `useCallback`).

2) Props & State
- Prefer lifting state up: form data ở parent khi cần tương tác API.
- Keep forms controlled; parse/validate trước khi gửi.

3) Async & Error handling
- Tất cả lỗi mạng hiển thị toast với thông điệp thân thiện.
- Thao tác có thể tái thử (retry) cho request không quan trọng.

4) File uploads
- Sử dụng `FormData` cho file uploads; gửi metadata dưới dạng fields.
- Hiển thị preview trước khi upload; upload sau khi resource chính đã được tạo để có `id`.

5) Testing
- Test key flows: tạo/sửa/xóa, import flow, upload hình.
- Đặt mock responses cho API để test UI behavior khi thành công/lỗi."
