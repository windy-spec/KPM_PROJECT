DEEP TOPIC — React Hooks (Tiếng Việt)

Mục tiêu
- Giải thích React Hooks từ cơ bản đến nâng cao bằng tiếng Việt, kèm ví dụ, khi nào dùng và những lỗi thường gặp.

1. Hooks là gì — ý tưởng chính
- Hooks là API cho phép dùng state và lifecycle trong functional components (không cần class).
- Vì sao cần: code ngắn gọn hơn, dễ test hơn, dễ tái sử dụng logic (qua custom hooks).

2. Các hook cơ bản
- useState(initial)
  + Lưu state cục bộ trong component.
  + Trả về [value, setValue].
  + Quan trọng: setValue là bất đồng bộ — nếu cần giá trị mới ngay lập tức, dùng updater function: setValue(v => v + 1).

- useEffect(effect, deps)
  + Chạy side effects (fetch, subscription, timers) sau render.
  + Nếu deps rỗng [], effect chạy 1 lần khi mount.
  + Trả về cleanup function để hủy subscription hoặc timers.
  + Lưu ý: tránh đặt hàm async trực tiếp vào effect — dùng IIFE async hoặc tách hàm ra.

- useRef(initial)
  + Lưu reference mutable không gây re-render.
  + Dùng để giữ DOM node (ref={el}) hoặc giữ giá trị giữa các render (ví dụ previous value, timer id).

- useMemo(fn, deps)
  + Cache giá trị tính toán nặng; chỉ tính lại khi deps thay đổi.
  + Dùng khi render có phép tính tốn kém.

- useCallback(fn, deps)
  + Trả về phiên bản hàm ổn định giữa các render để tránh re-render con khi truyền callback.
  + Kết hợp với React.memo cho tối ưu.

3. Custom Hooks
- Là hàm bắt đầu bằng "use" chứa logic có thể tái sử dụng (ví dụ useFetch, useForm).
- Trả về state và function giống component nhưng không render UI.
- Lợi ích: tách logic khỏi UI, dễ test.

4. Quy tắc khi dùng Hooks
- Chỉ gọi Hooks ở top-level (không gọi trong if/loop/try).
- Chỉ gọi Hooks trong React function components hoặc custom hooks.
- Vi phạm quy tắc sẽ dẫn đến thứ tự hooks thay đổi và lỗi runtime.

5. Mẹo và patterns phổ biến
- Debounce input search: lưu input state, dùng useEffect với setTimeout và cleanup để debounce.
- Fetch data: useEffect + async function bên trong; quản lý loading/error state.
- Form: dùng custom hook useForm để gom logic validate và bind inputs.
- Memoization: dùng useMemo cho list filter/sort; useCallback cho event handlers.

6. Những lỗi thường gặp
- Quên thêm dependency vào useEffect -> stale closure -> dữ liệu cũ.
- Thêm object/array trực tiếp vào deps (tạo ref mới mỗi lần) -> effect chạy liên tục. Giải pháp: memoize giá trị bằng useMemo hoặc truyền primitive.
- Lạm dụng useMemo/useCallback quá sớm -> phức tạp mà không cải thiện hiệu năng.

7. Testing Hooks
- Dùng React Testing Library + jest để test component dùng hooks.
- Test custom hook riêng bằng @testing-library/react-hooks (hoặc renderHook).

8. Ứng dụng trong project KPM
- useState dùng trong form modal (ví dụ ProductForm) để giữ các field.
- useEffect để fetch products/categories khi mount hoặc khi filter thay đổi.
- useRef để giữ file input hoặc tham chiếu tới DOM modal nếu cần focus.
- Custom hook gợi ý: `usePagination`, `useFetchCategories`, `useDebouncedValue`.

9. Khi cần chuyển sang class (hiếm khi)
- Hooks thay thế hầu hết trường hợp dùng class. Chỉ dùng class khi cần compat với legacy libs.

10. Kết luận — checklist khi dùng Hooks
- Đặt hook ở top-level.
- Suy nghĩ về dependencies của effect.
- Dùng cleanup nếu effect tạo subscription/timer.
- Tạo custom hook khi logic lặp lại.
- Profile/measurement trước khi tối ưu bằng memo.
